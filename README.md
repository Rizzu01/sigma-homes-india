# Sigma Homes India — Premium Parallax Next.js Website

## Stack
- Next.js App Router + TypeScript
- Vanilla CSS (no Tailwind)
- Framer Motion for scroll/parallax motion
- AOS for reveal animations
- Lucide icons

## Run
```bash
npm install
npm run dev
```
Then open http://localhost:3000.

## Design direction
Premium architectural editorial aesthetic: warm ivory, deep forest green and muted brass/gold; oversized typography; full-screen property hero; asymmetric layouts; generous whitespace; subtle borders; scroll-driven parallax.

## Images
Hero and chairman imagery currently use Unsplash URLs as temporary placeholders. Replace them with approved local assets under `public/images/` before production.
